## About the Project

This repository documents my journey of learning web design and front-end development. It contains small HTML and CSS exercises as well as a responsive restaurant website with navigation, menu, gallery, booking, and contact sections.

The main project, **Saffron Soul**, presents an authentic vegetarian Indian restaurant experience. Its forms include client-side validation and interactive feedback, while the layout is built with Bootstrap and custom CSS.

## Features

- Responsive navigation and page layouts
- Restaurant home page and featured dishes
- Categorized vegetarian menu
- Image gallery
- Table booking form with date, time, guest, and phone validation
- Contact information and contact form
- Scroll effects, gallery hover effects, and form success messages
- Google Maps integration
- Practice examples for HTML elements and CSS styling

## Getting Started

No build tools or dependencies are required. The project uses browser-ready files and loads Bootstrap and Font Awesome from CDNs.

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/vatsalshah2946/WEB-DESIGNING.git
   ```

2. Open the project directory.

3. Open the main practice project:

   ```text
   SELF PRACTICE/BWD PROJECT/index.html
   ```

You can open the file directly in a browser, or use the Live Server extension in Visual Studio Code for automatic refresh while editing.
